# Woordenlijst

| Term | Betekenis |
|---|---|
| **12V-batterij** | De hulpbatterij in een EV die de boordelektronica voedt. Is ze leeg, dan start de wagen niet, ook al is de tractiebatterij nog vol |
| **ADR** | Architecture Decision Record: een document dat één architectuurbeslissing en de reden ervoor vastlegt |
| **AFV** | Alternative Fuel Vehicle: een voertuig met een alternatieve aandrijving (EV, waterstof, LNG...) |
| **AIAG M-26** | Richtlijn van de Automotive Industry Action Group voor de behandeling van EV's in de logistieke keten |
| **BEV** | Battery Electric Vehicle: een volledig elektrische wagen |
| **C4-model** | Een methode om softwarearchitectuur te tekenen op vier niveaus: Context, Containers, Componenten, Code |
| **Compound** | Een opslagterrein voor nieuwe voertuigen, in de haven of in het binnenland |
| **CPMS** | Charge Point Management System: software om laadpalen te beheren |
| **Diepe ontlading** | Een batterij die zo ver leegloopt dat er blijvende schade kan ontstaan |
| **Dwell time** | De tijd dat een voertuig op de terminal blijft staan |
| **Dwell economy** | Het verdienmodel rond lange opslag: diensten zoals laden, PDI, opslag |
| **EMSA** | European Maritime Safety Agency |
| **EV** | Electric Vehicle (in dit project: BEV en PHEV) |
| **FVL** | Finished Vehicle Logistics: de logistiek van afgewerkte, nieuwe voertuigen |
| **HSE** | Health, Safety & Environment: veiligheid, gezondheid en milieu |
| **IMO** | International Maritime Organization (VN-agentschap voor scheepvaart) |
| **kWh** | Kilowattuur: een hoeveelheid energie |
| **MoSCoW** | Prioriteiten: Must, Should, Could, Won't |
| **OCPP** | Open Charge Point Protocol: de open standaard tussen laadpalen en beheersoftware |
| **OEM** | Original Equipment Manufacturer: hier de autofabrikant |
| **PCTC** | Pure Car and Truck Carrier: een schip voor het vervoer van wagens |
| **PDI** | Pre-Delivery Inspection: de controle en voorbereiding voor levering aan de dealer |
| **PHEV** | Plug-in Hybrid Electric Vehicle |
| **Regelprofiel** | In VoltYard: de set regels (laadtoestandsgrenzen, intervallen...) voor een fabrikant, model of aandrijving |
| **RoRo** | Roll-on/Roll-off: schepen waar vracht op- en afrijdt |
| **SOC** | State of Charge: de laadtoestand van de batterij in % |
| **SoH** | State of Health: de gezondheid van de batterij tegenover nieuw |
| **TOS** | Terminal Operating System: de centrale software van een terminal |
| **VIN** | Vehicle Identification Number: het unieke chassisnummer van 17 tekens |
| **Yard** | Het terrein van de terminal waar voertuigen staan |
