# Validation hypotheses

No interviews or operational results have been recorded. The application is a test instrument, not evidence that demand exists.

| ID | Hypothesis | Evidence to collect | Proposed pass criterion |
|---|---|---|---|
| H1 | Multiple OEM instructions create manual coordination work | Three concrete recent cases from different roles | At least two organisations describe repeated avoidable work |
| H2 | Missing inspection evidence affects handover/reconciliation | Anonymised forms or reconstruction walkthrough | Two examples where a shared VIN history would change a decision |
| H3 | Operators can record useful observations quickly | Timed test with three operators using fictional VINs | Median below 30 seconds with no critical field errors |
| H4 | Charging prioritisation improves planning | Planner ranks tasks before seeing VoltYard | Comparable or better prioritisation with explainable differences |
| H5 | HSE workflow reflects actual authority | HSE review of concern → isolation → decision | Named owner accepts the states and required evidence |
| H6 | Buyer will fund a pilot | Budget-owner interview and procurement process | Written willingness to evaluate a defined paid or sponsored pilot |
| H7 | Integration is feasible | IT confirms data ownership and sample export | Lawful, documented CSV/API path without shared production credentials |

## Research sequence

Recruit 3–5 participants across planning, field operations, HSE and IT/commercial. Start with existing work, then observe the prototype task. Record contrary evidence, not only supporting comments. A polite compliment is not validation.

## Evidence register

For each finding record anonymous interview ID, date, role, question, observed behaviour or quotation, interpretation and effect on the backlog. Store identifiable notes outside the repository. Record consent before recording audio.

## Decision gate

Proceed to a supervised pilot only when a workflow owner, a profile approver and a data owner are identified. Revisit scope if operators already have a suitable tool or cannot reliably observe the required fields.
