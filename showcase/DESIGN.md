# VoltYard showcase design

The site introduces a real portfolio project to recruiters and terminal-domain readers, then invites them to try a fictional-data sandbox.

Palette: marine #164E63, deep marine #123E4D, ice #EDF3F5, white #FFFFFF, ink #142F3A, signal amber #E6BB49. Typography uses the system's Avenir Next/Segoe UI family, with tight, large headings and restrained body text. No external fonts or trackers are required.

The memorable element is an illustrative terminal layout with selectable zones and real fixture occupancy. It expresses the domain more directly than a generic hero illustration. The rest is quiet: a left-aligned project introduction, a real dashboard capture, workflow links, an architecture explanation, tested evidence and a named author.

The public sandbox runs only in the browser. Server authentication, permissions and durable storage belong to the separately runnable .NET application. The interface and case study state that boundary explicitly.
